# 📖 About this Repository

Welcome to the **Agentic AI with Azure AI Foundry** repository created for the **Accenture Advanced AI Corporate Training Program (August 2026)**.

This repository contains enterprise-grade learning materials, hands-on labs, notebooks, sample applications, multi-agent implementations, workflow orchestration examples, MCP integrations, Agent-to-Agent (A2A) communication, observability, governance, evaluation techniques, and real-world capstone projects.

The course is designed for software engineers, AI developers, architects, and enterprise solution teams who want to build scalable Agentic AI applications using Microsoft's AI ecosystem.

# ⚙ Installation

Clone the repository

```bash
git clone https://github.com/avyuktitech/Agentic-AI-Accenture-Aug-2026.git
```

Move into the repository

```bash
cd Agentic-AI-Accenture-Aug-2026
```

Install dependencies

```bash
pip install -r requirements.txt
```

Execute Python labs


Execute tests
